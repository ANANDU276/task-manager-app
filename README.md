# Task Manager App

A responsive Task Manager web app built with **React, Vite, React-Bootstrap, Bootstrap, SCSS, React Router, Context API, and Axios**.  
Supports authentication, task CRUD, filtering, and dark/light theme toggle.

---

## Features
Local authentication (signup, login, logout with localStorage)
Task CRUD (create, edit, delete, toggle, mark important)
Fetch initial tasks from [JSONPlaceholder](https://jsonplaceholder.typicode.com)
Persistent state using localStorage
Task filtering with search and URL params
Dark/Light theme toggle
Responsive design with Bootstrap + SCSS
Built with Vite for fast development
